# Elektronika Dasar (Basic Electronics)

Arduino sketches from the Basic Electronics course final project (Semester 2).

| File | Description |
|---|---|
| `Final-Project/DUST.ino` | Optical dust-sensor reading (analog A0, LED-pulsed sampling) |
| `Final-Project/PROJECT_FP_sulit.ino` | Weather-station logger: wind vane, DS3231 RTC, 20x4 I2C LCD, SD-card logging |

Coursework, Geophysical Engineering, Institut Teknologi Sepuluh Nopember (ITS).
Raw data files larger than 10 MB, QGIS project files, rasters, and report documents (PDF/DOCX/PPTX) are kept offline and not included.
